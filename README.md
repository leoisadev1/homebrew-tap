# Homebrew Tap for Better Monitor

Install Better Monitor with Homebrew:

```sh
brew install --cask leoisadev1/tap/better-monitor
```

Upgrade when new releases are published:

```sh
brew update
brew upgrade --cask better-monitor
```

Uninstall:

```sh
brew uninstall --cask better-monitor
```

Better Monitor itself also includes Sparkle updates through **Better Monitor > Check for Updates...**.
